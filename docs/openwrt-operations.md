# OpenWrt fleet capture and staged management

The [Arteria decision](arteria-gateway.md) selects NixOS Arteria/thebeyond for routing and the Flint 2/BT8Bridge path for wireless transit. OpenWISP is selected for OpenWrt image and configuration management; deployment awaits stable gateway/mesh acceptance and a separate trusted calvard infrastructure cluster. Do not host device credentials in erebonia’s CI/development cluster. Existing [build/deploy entry points](openwrt-deployment.md) describe repository tooling, not authority to overwrite controller-owned settings.

Capture each actual device independently, including Flint 2, BT8Bridge, other BT8s, E8450 and switches: board/release, partition layout, package inventory, redacted UCI, cabling/ports, routes/firewall, and healthy wireless/mesh observations. Keep raw backups, factory/calibration/bootloader data and credentials encrypted outside Git. Compare the registry with [dated BT8 evidence](network/bt8-observed-state.md); record actual roles and resolve contradictions before changes. The old spare→bridge→gateway BT8 rotation is superseded; a remaining BT8 needs an explicit coverage/recovery role before deployment.

Qualify pinned shared firmware and required packages per hardware model, separately from operational configuration. Stock-boot BT8 support must be proven; no ubootmod conversion is assumed. Preserve image digests and supported wired/console recovery paths. Use initial 5 GHz non-DFS 80 MHz with `mesh_fwding=0` beneath batman-adv only after hardware/regulatory and peer compatibility checks; record approved deviations. Test wired remote-client throughput/loss/latency with doors open/closed, MTU, VLAN tagging, DHCP/RA passthrough, reboot and mesh reconnection before depending on the path. Bridges and switches must not introduce DHCP/RA servers.

OpenWISP owns approved operational SSID, VLAN, mesh and management settings; retain model image/package definitions and recovery artifacts in Git. Avoid competing flake configuration writers. Bootstrap registration, certificate trust and controller connectivity over Ethernet: a mesh-only unenrolled device cannot fetch its first mesh configuration. Prove factory-reset enrollment, controller-offline reboot/transit and direct management with the agent disabled before fleet adoption. Controller connectivity checks do not prove all VLANs, BATMAN forwarding or client isolation.

Pilot one firmware upgrade with all required packages and compatible local mesh/management configuration preserved, so the node can rejoin without first fetching configuration. Record outage and service recovery, and rehearse wired/console recovery if the device fails to return. Configuration rollback is not firmware rollback. Upgrade peripheral nodes individually, Flint 2 and BT8Bridge separately, and the switch in its own window; keep controller-cluster maintenance separate.

The current OpenWrt outputs expose only BT8Bridge; Flint 2 and switch configuration are not reconstructed by this flake. The registry places Arseille on VLAN 10 with reclassification deferred. Confirm unmanaged switch firmware, management address and physical ports on site. Establish and verify a new management path before removing old access; test tagging/PVID/trunks and per-port PoE with a harmless load. Keep direct recovery available through soak. [Arseille GS108Tv3 placement](https://forgejo.internal/mutantmell-net/dotfiles/issues/233) is distinct from GS1900 PoE acceptance.

NixOS gateway acceptance owns permitted/denied dual-stack flows, DNS/NTP and VLAN-51 isolation. Verify positive RA router lifetime, actual ULA-only client default route/RDNSS without delegated GUA, using NixOS/networkd rather than the retired OpenWrt gateway mechanism. Keep the Arteria NUC recovery path and never run duplicate gateway identities. For edge-exposure changes, record the [off-network WAN audit](network/wan-audit.md) against the deployed commit. Every accepted device needs firmware/configuration identities, recovery artifacts and a live acceptance record; Git configuration alone is not deployment proof.
